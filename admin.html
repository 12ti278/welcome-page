后台管理

用 GitHub 访问令牌登录。内容会提交到仓库，GitHub Pages 构建完成后全站生效。

如何创建令牌？
  1. 打开 GitHub 的 Fine-grained tokens 页面。
  2. Repository access 选择 Only select repositories → 12ti278/welcome-page。
  3. Permissions → Repository permissions → Contents: Read and write；想看构建状态的话再加 Pages: Read。
  4. 生成后粘贴到上方。令牌只保存在当前标签页，关闭页面即失效，不会写进任何网站文件。

这是纯前端后台：登录凭据就是你的 GitHub 令牌，数据直接提交到本仓库。请只在私人电脑上使用，不要把令牌发给别人。

登录与安全

登录用的是 GitHub fine-grained token，权限只覆盖本仓库的 Contents（读/写）。令牌保存在 sessionStorage，关闭标签页即清除；它不会写进 HTML、不会提交到仓库，也不会出现在任何日志里。

这个后台是纯静态页面：能访问 admin.html 的人很多，但没有你的令牌就无法读写仓库。令牌泄露时，请立刻到 GitHub 撤销并重新生成。
