01 / Project Overview

项 目 展 示

✦
Featured Project

时光商社

Vintage Mercantile

完整的中古商城全栈项目，复古亚马逊风格UI，17件精选中古商品，支持SKU规格、物流追踪、商品推荐、浏览埋点等进阶功能。 前端采用 React + TypeScript + Vite + Tailwind 构建，后端基于 Express + MySQL + JWT， 运用乐观锁机制防止超卖，通过数据库索引优化查询性能，打造兼具美学与技术深度的复古电商体验。

React TypeScript Vite Express MySQL TailwindCSS 全栈 复古风
